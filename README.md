### 🛡️ CrashGuard Engine

A standalone Windows application for **game integrity scanning, crash analysis, and safe recovery**.

- Automatic discovery for popular game platforms
- Read-only, cancellable integrity scans
- Evidence-based crash and mod diagnostics
- Turkish and English interface
- Self-contained Windows x64 distribution

## Engineering principles

> **Useful over flashy. Safe over surprising. Evidence over assumptions.**

- Build for real users and real problems
- Make risky actions explicit and reversible
- Keep interfaces clear, responsive, and accessible
- Prefer measurable evidence over vague guesses
- Document decisions so projects remain maintainable
